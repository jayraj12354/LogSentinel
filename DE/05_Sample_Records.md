## 8. Integrity & Referential Verification Summary

- **Foreign Key Validity**: Every `log_entries.source_id` maps to an existing `sources.id`. Every `alerts.policy_id` maps to an existing `alert_policies.id`.
- **Constraint Compliance**:
  - `alerts.status = 'ACKNOWLEDGED'` contains a non-null `acknowledged_at` and valid `acknowledged_by` user ID (`chk_alert_ack`).
  - `alerts.window_end >= alerts.window_start` holds true (`chk_alert_window`).
  - `users.email` adheres to valid RFC email format (`chk_users_email`).
  - `import_batches` metrics (`lines_total >= 0 AND lines_ok >= 0`) hold without exception.
